T-01 → T-02 → T-03 → T-04 → T-05 → T-06 → T-07…T-09 (тести) → T-10 → T-11 → T-12.

Тести пишуться після відповідної функції, але **очікування** для них уже зафіксовані в
`spec.md` (розділи 4–6) до реалізації.
