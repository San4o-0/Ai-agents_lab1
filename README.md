# Лабораторна 1 — журнал несправностей авто з перевіреною AI-функцією

Сервіс веде журнал несправностей авто: запис можна створити вручну, подивитися список
записів і підготувати запис із короткого повідомлення водія за допомогою LLM.
Пропозицію моделі сервіс перевіряє і лише після цього зберігає.

Стан репозиторію: **етап 1 — дослід до сервісу**.

- `notebooks/01_experiment.ipynb` — виконаний дослід: правила проти LLM на 10 зафіксованих
  повідомленнях, детерміновані перевірки валідатора, експеримент із двома інструкціями
  і висновок для специфікації.

Специфікація, сервіс, тести й зовнішня перевірка додаються наступними етапами.

## Запуск досліду

```powershell
uv sync --group dev
Copy-Item .env.example .env   # далі вписати OPENAI_API_KEY для живої частини
uv run jupyter lab
```

Без ключа детерміновані перевірки виконуються, а жива частина позначається `not_run`.
